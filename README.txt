Titre
Projet Poudlard - L'Art de Coder comme un Sorcier


Description
Ce projet consiste à developper un jeu d'aventure interactif en Python, dans l'univers d'Harry Potter.
Le but étant de faire gagner sa maison.

Contributeurs
HUANG Tony - SC2
GERARD Theophane - SC2
Binôme 1

Réalisé sur python - 4 chapitres.
Le jeu contient :
    -chapitres
        -chapitre_1.py
        -chapitre_2.py
        -chapitre_3.py
        -chapitre_4.py
        -chapitre_5_extension.py
    -data
        -equipes_quidditch.json
        -inventaire.json
        -maisons.json
        -quiz_magie.json
        -sorts.json
    -univers
        -maison.py
        -personnage.py
    -utils
        -input_utils.py
        -main.py
        -menu.py
        -README.txt

Fonctionnalités Principales
- Création et gestion d’un personnage (attributs, inventaire, sorts)
- Système de choix interactifs influençant l’histoire
- Répartition automatique dans une maison de Poudlard
- Apprentissage de sorts aléatoires
- Quiz magique avec attribution de points
- Simulation complète d’un match de Quidditch
- Gestion des points des maisons
- Utilisation de fichiers JSON pour les données du jeu

Utilisation
Exécuter le fichier main.py et lancer le programme afin de débuter l'aventure
